What happens when I press Start?

EasyHost finds the newest Minecraft version, downloads the matching Java and server files (only the first time), writes the settings, and starts the server. Everything lives in its own folder, nothing is installed on your system.

Joining yourself

In Minecraft go to Multiplayer → Add Server and enter localhost.

Friends at your home

They use the Same Wi-Fi address shown on the left.

Friends somewhere else

They use the Over the internet address. For this the port must be open on your router. EasyHost tries this automatically (UPnP). If it says it could not:

  • Turn on UPnP in your router's settings, or set up a port forward for TCP port 25565 to this PC.
  • If EasyHost says your provider uses CGNAT, port forwarding cannot work. A free tunnel such as playit.gg gives you an address that works anyway.
  • The first start asks for permission to add a Windows Firewall rule. Say yes, or friends can't connect.

Mods and plugins

With Paper you add plugins. They run only on the server, so friends join with normal Minecraft. With Fabric you add mods, which can add new things to the game; mods marked "players need it too" must also be installed by everyone, together with Fabric. Install and remove them on the Plugins/Mods tab, then restart the server.

Simple Voice Chat works on both. Every player needs the voice chat mod in their own Minecraft. EasyHost also opens its voice port (UDP 24454).

Seeds and existing worlds

On the World tab you can start a new world from a seed, play one of your singleplayer worlds with friends, or upload a world someone sent you as a zip. The current world is always backed up first, and you can restore any backup there.

Making yourself admin

Go to Players, type your name and press Make admin. Then you can use commands like /gamemode creative in game.

Where is my world?

Press Server folder. The world folder is your world. Use Back up world before big changes.

Closing the app

Closing this window saves the world and stops the server cleanly.
